Opa, você chegou aqui! Este projeto foi criado como um espaço simples e prático para quem está começando a aprender Git e GitHub. A ideia é mostrar, de forma gradual e acessível, como criar repositórios, fazer alterações, registrar versões com commits e compartilhar seu trabalho com outras pessoas.

Ao longo do processo, você vai ter a oportunidade de praticar comandos essenciais, entender o fluxo de trabalho em equipe e perceber como o Git ajuda a organizar projetos de forma segura e eficiente. Esse material foi inspirado em conteúdos estudados em cursos de YouTube e Udemy, e tem como objetivo facilitar seus primeiros passos no mundo do controle de versão.

Conheça o tutorial completo no [Workshop Primeiros Passos com Git](https://apprendendo.blog/curso/workshop-primeiros-passos-com-git/)
